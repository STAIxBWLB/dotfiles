dotfiles moves from entelecheia/dotfiles-v2 to STAIxBWLB/dotfiles, and the Homebrew formula moves from the entelecheia/tap tap to staixbwlb/cask.

### Improved
- `dot update`, the curl installer and Homebrew now point at STAIxBWLB/dotfiles and `staixbwlb/cask/dotfiles`. Files `dot` manages keep their existing names and markers, so they do not change on existing hosts. (#257)

### Action needed
- Homebrew users: run `brew update`, which migrates the install to the new tap. If `brew info dotfiles` still shows entelecheia/tap, run `brew trust staixbwlb/cask` and then `brew reinstall staixbwlb/cask/dotfiles`.
- Curl-installer users need nothing: `dot update` follows the move. The first update from an older version may wait once for the full maintenance resource check.
