## dot ai agents show

Print the raw or rendered agents SSOT

```
dot ai agents show [flags]
```

### Examples

```
  dot ai agents show
  dot ai agents show --rendered codex
```

### Options

```
  -h, --help[=true|false]                help for show
      --rendered string                  print SSOT rendered for one tool
      --with-line-numbers[=true|false]   prefix output with line numbers
```
