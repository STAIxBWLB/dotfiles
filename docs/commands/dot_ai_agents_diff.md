## dot ai agents diff

Show rendered-vs-live diff for agents targets

```
dot ai agents diff [flags]
```

### Examples

```
  dot ai agents diff
  dot ai agents diff --tool codex
```

### Options

```
  -h, --help          help for diff
      --tool string   comma-separated tool IDs to diff
```
