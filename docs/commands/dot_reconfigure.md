## dot reconfigure

Re-run init prompts with current values as defaults

### Synopsis

Edit existing dot configuration interactively, then optionally apply.

```
dot reconfigure [flags]
```

### Options

```
  -h, --help   help for reconfigure
```

      --home string     Override home directory (for admin setup of other users)
