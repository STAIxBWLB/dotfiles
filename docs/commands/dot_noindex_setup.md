## dot noindex setup

Install the periodic noindex sweep as a LaunchAgent

```
dot noindex setup [flags]
```

### Examples

```
  dot noindex setup
```

### Options

```
  -h, --help                help for setup
      --interval duration   how often to sweep (default 6h0m0s)
```
