## dot apply

Apply dot configuration

### Synopsis

Apply the selected profile's configuration to the user environment.

```
dot apply [flags]
```

### Options

```
  -h, --help             help for apply
      --module strings   Run specific modules only
      --profile string   Profile name (minimal, full, server)
```
