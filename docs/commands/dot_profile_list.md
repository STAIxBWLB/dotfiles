## dot profile list

List available profile snapshots for this host

```
dot profile list [flags]
```

### Examples

```
  dot profile list
```

### Options

```
      --from string   backup root (overrides configured BackupRoot)
  -h, --help          help for list
      --host string   hostname to list (default: this host)
```
