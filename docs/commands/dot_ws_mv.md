## dot ws mv

Rename/move a directory on both workspaces

```
dot ws mv <src> <dst> [flags]
```

### Examples

```
  dot ws mv work/dev/old work/dev/new
```

### Options

```
  -h, --help[=true|false]   help for mv
```
