## dot ai export

Export AI settings to a portable tar.gz archive

```
dot ai export <file.tar.gz> [flags]
```

### Options

```
  -h, --help           help for export
      --include-auth   Include auth/local-secret files
      --tag string     Human-friendly label stored in meta.yaml
```
